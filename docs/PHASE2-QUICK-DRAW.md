# المرحلة 2: عقد الرسم السريع

## تجربة المستخدم

الرسم السريع لا يغيّر قواعد CivilDraft الهندسية؛ هو يختصر الوصول إليها:

1. نقطة بداية.
2. طول مباشر وزاوية اختيارية.
3. نقاط متتابعة مع معاينة واضحة.
4. إغلاق تلقائي عند الرجوع إلى البداية.
5. التزام واحد لكل شكل، لذلك التراجع يعكس العملية كاملة.

## الدوال الحالية

- `nextPointFromLength`: يحسب النقطة التالية من طول وزاوية دون لمس الحالة.
- `rectangleFromCorners`: يحول ركنين إلى أربعة أركان مرتبة.
- `closePolygon`: يتعرف على الرجوع إلى نقطة البداية ضمن تفاوت معلن.
- `drawingCommitPlan`: يبني خطة مقاطع مغلقة، تمهيداً لتمريرها إلى `edit()` و`addWall()`.

## قواعد تجربة الرسم

- لا دمج تلقائي للجدران الموجودة.
- لا تقريب صامت؛ الالتقاط المرئي يقرر النقطة قبل الالتزام.
- لا إنشاء جزئي عند فشل مقطع؛ العملية كلها معاملة واحدة.
- الطول المدخل يُقاس بالمليمتر بعد تحويل واجهة الإدخال.
- كل شكل مغلق ينتج رسالة واضحة بعدد المقاطع والمساحة/الأبعاد.

## بوابة التنفيذ التالية

ربط `drawingCommitPlan` بأداة `rect` و`wall` الحالية خلف خيار وضع الرسم السريع، ثم اختبار المتصفح: رسم مستطيل، تعديل طوله، إضافة فتحة، والتراجع بخطوة واحدة.
