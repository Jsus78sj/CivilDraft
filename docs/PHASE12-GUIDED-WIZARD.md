# المرحلة 12: معالج الغرفة المرئي

أضيفت نواة معالج محضة تحافظ على ترتيب التجربة: **المقاس → الاسم → الباب → المعاينة**.

المعالج لا يكتب في حالة CivilDraft؛ بعد أن تصبح المعاينة `ready` فقط تستدعي الواجهة `commitGuidedRoom` في معاملة واحدة. زر الإلغاء يعيد المعالج للبداية، والمدخلات العربية والفارسية تمر عبر نفس محلل الأبعاد.
